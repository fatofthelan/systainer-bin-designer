# Notices

## Bin geometry

The bin geometry (grid pitch, foot rings, rim, chamfer and the user parameter
names) is derived from:

> **Tanos/Festool Systainer Organizer Insert (parameterized)** by **Heyus**
> https://www.printables.com/model/208217 (also published on Thingiverse as thing:5200085)
> Licensed under Creative Commons Attribution 4.0 International (CC BY 4.0):
> https://creativecommons.org/licenses/by/4.0/

Changes from the original:
- the model is generated by code instead of being a single parametric file;
- the foot pattern uses construction axes, so it no longer flips direction when the unit count changes;
- a "tuned" fit preset (grid pitch 24.95 mm, nub opening 14.9 mm, no extra nub padding,
  foot squares 2 mm smaller, rim 12 mm), adjusted through test prints, is the default;
- generated internal dividers and compartments were added.

This repository doesn't redistribute the original model file.
