# Changelog

## 1.0.0

First public release.

- Palette UI: grid sizing, compartment editor (click or drag, quick split, ½-unit grid, undo/redo), live 3D preview.
- Parametric bin with template-compatible user parameters and exact generated dividers.
- Create in a new document, update in place (one undo step), optional auto-update.
- Read-back verification after every build.
- STL, 3MF and STEP export with versioned file names.
- Fit presets (Tuned, Template), editable tolerances, and loading fit values from an open bin.
- Saved layouts and settings in a per-user data folder.
- Unit tests, a Python/JavaScript parity test, and a Fusion integration test.
